# Repository Review Checklist

## Purpose

Use this checklist when reviewing repositories manually or when validating AI-assisted repository modifications.

---

# General

- [ ] README exists
- [ ] README is up to date
- [ ] PDF exists
- [ ] No broken links
- [ ] No missing images

---

# Paper Review

- [ ] Abstract reviewed
- [ ] Conclusion reviewed
- [ ] Terminology consistency verified
- [ ] Figure numbering verified
- [ ] Caption consistency verified

---

# Repository Structure

- [ ] Folder structure is clean
- [ ] Duplicate files removed
- [ ] Temporary files removed
- [ ] Navigation is clear

---

# Research Program Integration

- [ ] Research-Portfolio link exists
- [ ] Related paper links exist
- [ ] Concept genealogy preserved
- [ ] Research context preserved

---

# AI Work Verification

- [ ] AI-created files reviewed
- [ ] AI-moved files reviewed
- [ ] AI-deleted files reviewed
- [ ] Research intent preserved
- [ ] Human approval completed

---

# Final Decision

- [ ] Repository approved
- [ ] Additional revisions required
