# Image Standardization Guide

## Purpose

Establish a unified visual style across Papers 1–4 and related research assets.

---

# Core Principle

All figures should appear as if they belong to a single research program.

---

# Figure Numbering

Use a consistent format:

Figure 1
Figure 2
Figure 3

---

# Caption Style

Format:

Figure X. Short descriptive sentence.

Example:

Figure 7. Checkerboard pattern generated by odd Hamming-weight layers.

---

# Typography

Use one consistent font family throughout all figures.

Verify:

- Figure labels
- Axis labels
- Captions
- Annotations

---

# Image Dimensions

Prefer consistent aspect ratios and resolutions.

Verify:

- Export quality
- Readability
- Print suitability

---

# Color Rules

Use a consistent visual convention across papers.

Examples:

- 0 = White, 1 = Black
- 0 = White, 1 = Gray

Do not mix conventions without justification.

---

# Line Style

Standardize:

- Grid lines
- Borders
- Arrows
- Highlight boxes

---

# Prohibited

- Different styles for similar figures
- Inconsistent fonts
- Inconsistent color meanings
- AI-generated figure styles that conflict with existing papers

---

# Review Question

Can this figure be placed into Papers 1, 2, 3, or 4 while still appearing to belong to the same research program?
